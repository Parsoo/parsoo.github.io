# Generative AI Homework #1 — AI Interaction Log

This log summarizes five significant interactions from the actual website workflow. The prompts and results are paraphrased rather than presented as exact quotations.

## 1. Ideation and specification

**Prompt / purpose:** I asked ChatGPT to help define the purpose, audience, information architecture, and content for a personal portfolio for my Generative AI course.

**Selected result:** We shaped the site around a professor-facing portfolio that communicates my background, research interests, and current projects quickly.

**My note:** I supplied the course context and personal facts, and set a clear constraint against inventing biography or contact details. I used the resulting section plan as the basis for the site.

## 2. Design direction

**Prompt / purpose:** I asked AI to develop a visual direction for a modern AI portfolio that would feel professional and restrained.

**Selected result:** A dark, neutral foundation with strong typography, one lime accent, subtle technical diagrams, minimal motion, and responsive layouts.

**My note:** I kept the CSS-generated system and project visuals because they relate to the work described. I avoided adding stock AI imagery or visual effects that would distract from the content.

## 3. Initial implementation

**Prompt / purpose:** I asked ChatGPT to turn the agreed content and visual direction into a simple website using HTML and CSS.

**Selected result:** A working first version with navigation, About, research interests, projects, an education and experience timeline, and contact details.

**My note:** I reviewed the generated page and supplied the email addresses and GitHub username for the contact links. The implementation remained plain HTML and CSS; JavaScript was unnecessary.

## 4. Agentic implementation with Codex

**Prompt / purpose:** I asked Codex to work in my actual assignment folder, inspect the existing files, and refine the implementation while preserving the design.

**Selected result:** Codex edited the project files directly, corrected an unsupported location label, improved text contrast, and reviewed the page in a browser. Codex also created the public GitHub Pages repository and published the site.

**My note:** Seeing an agent work with real files was useful to me. The agentic nature of Codex is the part of AI I particularly like and want to master. I still reviewed the site and decided what personal information to provide.

## 5. Audit and verification

**Prompt / purpose:** I asked Codex to audit the existing website against the homework checklist before finishing the submission.

**Selected result:** The website and deployment were largely complete, but the audit found the missing Chinese name and student ID, as well as the missing interaction log and reflection deliverables.

**My note:** I provided my confirmed Chinese name and student ID and asked Codex to finish the remaining documentation. I used the audit to distinguish a site that looks finished from a submission that includes every required item.
